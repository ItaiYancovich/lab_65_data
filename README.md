# lab_65_data
Data upload repository for lab 65

## Contents

- `fit_coil_impedance.py` — fits RL and RLC coil models to PicoScope frequency-sweep CSV data.
- `kalman_filter_bench.html` — an interactive visualisation of a 1-D Kalman filter tracking a
  moving target through sensor noise. Open the file in any browser; it is self-contained, with no
  build step and no network access. Play the run, scrub to any step, drag the noise sliders, and
  cut the sensor out mid-run to watch the uncertainty band open up.
